# 3D-Shader-Course-Kevin-Hamberg

Provide a short README or equivalent explaining the environment, prerequisites, how to build/run the project and any controls needed for the demonstration. Include a runnable build/executable when practical.
The project features a scene with 2 light sources that are represented by cubes and a Toon Link model. To run the project you open the slnx file with your IDE of preference to build and run the program.
The controls for the demonstration is WASD for movement of the camera, as well as mouse aiming to look around and the arrow keys to move Link.
